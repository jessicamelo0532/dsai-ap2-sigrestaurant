# Organização do trabalho

Este diretório registra decisões humanas de execução do projeto, conforme a estrutura sugerida na atividade. Não contém skills nem instruções automáticas para agentes.

- Uma especificação datada deve ser registrada antes do código que ela descreve.
- Commits pequenos devem declarar `Agent:` e `Spec:` no corpo da mensagem.
- Regras do restaurante e formas de validação ficam descritas na especificação e no README.
- Nunca versionar arquivos `.env`, senhas reais ou outros segredos.
- As conversas fornecidas pelo ambiente devem ser registradas em `prompts/sessoes/` sem reescrita; se uma exportação bruta não estiver disponível, documentar essa limitação.
